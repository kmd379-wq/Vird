# Обновление реестра патентных поверенных

Основной источник: data.json. Excel и интерактивная таблица — представления этих данных. Сохранять стабильные ID кандидатов и Gmail message ID, не дублировать письма при повторной проверке.

Область: только торговые системы PPA №1–10, NPPA, PCT, патентная охрана РФ и связанные переходы прав. Не читать и не включать письма Тимофеевой и партнёров по производству вагонов.

При каждой следующей проверке почты по поручению Михаила:
1. Найти новые письма только по патентным кандидатам и теме проекта; проверить вложения по смыслу.
2. Добавить сообщения в журнал с датой, направлением, источником и содержанием.
3. Обновить последний ответ, исходящее письмо, ожидаемый следующий шаг и срок. Срок, запрошенный нами, не считать обещанным кандидатом.
4. Различать NDA: не направлен; шаблон отправлен; правки получены; подписан получателем; подписан обеими сторонами. Хранить ссылку на доказательство подписи и версию, когда они появятся.
5. Отдельно фиксировать передачу краткого перечня задач и полного конфиденциального технического комплекта. Не считать одно другим.
6. Записывать суммы вместе с валютой, количеством заявок, включёнными услугами, пошлинами, налогами, платформой, авансом, сроком действия и исключениями. Пустое поле не равно нулю. Не складывать альтернативные услуги.
7. Указывать окончательную смету только после получения подтверждённого полного предложения. До этого не присваивать победителя по цене.
8. Сохранять отказы и прежнего поверенного, исключая их из активного сравнения.
9. Пересоздать Excel через build.mjs и обновить встроенные данные в patent-attorney-tracker.canvas.tsx; сохранить ручные заметки при изменениях.

Фоновая автоматическая проверка почты не настроена. Этот реестр обновляется при работе в чате, а не самостоятельно.

Подписанных NDA не найдено. Данные компании о страховании и регистрации специалистов пока не прошли независимую проверку.
