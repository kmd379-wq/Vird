4. Потоки стрелками

  1. Пользователь → интерфейсы → контроллер — лицо в биокамеру, команды на дисплей/в приложение, платёжные данные.
  2. Контроллер → режим — продукты: цена по сроку и скорости продаж, LED; ограниченные товары: возраст → pre-auth депозит → замок.
  3. Полки ↔ контроллер — RFID и камера в «передней зоне»; рука без метки = тревога / удержание депозита.
  4. Индукция → запасы — персонал до загрузки связывает штрихкод, RFID и срок годности.
  5. Контроллер ↔ шлюз / offline-буфер — online hold и списание; offline локальный депозит и сверка.
Ядро PPA №1: защищённый шкаф с RFID-полками и камерой, локальным ИИ-контроллером, динамическими ценами на скоропорт и биометрическим доступом с депозитом для алкоголя/табака — с работой без сети.
