# Фигуры 1–22 — что на них (по описанию Ken)

Чертежи 1–22 в комплекте Ken — **на английском**. Русский перевод прислан только для 23–30.

- ФИГ. 1 представляет собой вид спереди автономного розничного шкафа, показывающий общую компоновку оборудования, включая дверь, обращенный к пользователю дисплей, биометрическую камеру / камеру проверки возраста, платежный интерфейс и внутренние интеллектуальные полки.

- ФИГ. 2 представляет собой вид сбоку в разрезе шкафа по ФИГ.

- ФИГ. 4 представляет собой схематический вид системы активного выравнивания, включая моторизованную выравнивающую опору, ее привод и датчик наклона.

- ФИГ. 5 представляет собой блок-схему процедуры выравнивания, выполняемой контроллером.

- ФИГ. 7 представляет собой вид сбоку модуля гравитационной подачи с затвором.

- ФИГ. 8A представляет собой вид сбоку модуля гравитационного лотка с датчиком температуры.

- ФИГ. 8B представляет собой вид сбоку модуля автоматического сброса и интеллектуального отсека отходов.

- ФИГ. 9 представляет собой детальный вид сбоку геометрии детектирования в передней части модулей, показывающий поле обзора камеры, антенную матрицу, дисплей на кромке полки, зону высокой ценности и стандартную зону.

- ФИГ. 10 представляет собой блок-схему процедуры сенсорного комплексирования для подтверждения извлечения изделия.

- ФИГ. 11 представляет собой блок-схему процедуры последовательности гравитационной подачи с затвором.

- ФИГ. 13 представляет собой блок-схему процедуры доступа пользователя и сеанса.

- ФИГ. 14 представляет собой блок-схему граничного контроллера и его соединений с оборудованием шкафа и с удаленными системами.

- ФИГ. 15 представляет собой схематический вид кластерного развертывания, имеющего ведущий блок и ведомые блоки.

- ФИГ. 16 представляет собой вид сбоку в разрезе модуля термообработки.

- ФИГ. 17A представляет собой вид в поперечном разрезе, а ФИГ.

- ФИГ. 18A представляет собой вид в поперечном разрезе составного сосуда.

- ФИГ. 18B представляет собой вид сверху лотка с избирательным нагревом.

- ФИГ. 19 представляет собой блок-схему процедуры термообработки.

- ФИГ. 20 представляет собой схематический вид модуля жидкостной обработки и дозатора принадлежностей.

- ФИГ. 21A представляет собой вид сбоку в разрезе плавающего интеллектуального бункера.

- ФИГ. 21B представляет собой схематический вид станции для плодоовощной продукции с выходным контрольным шлюзом.

- ФИГ. 22 представляет собой блок-схему локальных и вышестоящих рабочих процессов регистрации товара.
