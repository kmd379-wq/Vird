The application may present a product “digital twin” for physical units inside the cabinet by displaying batch-specific data including an exact expiration date and a scheduled purge time, and the application mirrors dynamic price changes in substantially real time. In embodiments, the system implements an “ad handshake” protocol that synchronizes context from the mobile application to the cabinet screen, such that a user search or selection in the application (e.g., “cables”) causes the cabinet display to present related promotions and highlight corresponding shelf locations upon the user approaching the cabinet.
