Формула изобретения

1. Автомат с накопительным (развесным) хранением, содержащий: накопительный бункер, выполненный с возможностью хранения россыпных скоропортящихся товаров; контейнер для утилизации, расположенный в зоне, доступной покупателю; тензодатчик утилизации, выполненный с возможностью измерять массу каждого товара, помещённого в контейнер для утилизации; модуль взвешивания бункера, выполненный с возможностью измерять нагрузку на бункер; дисплей; платёжный терминал; центральный контроллер, выполненный с возможностью вести счётчик утилизаций и регистр массы утилизации в рамках транзакции; и модуль ИИ-ценообразования, выполненный с возможностью рассчитывать индекс порчи по данным о массе утилизированного товара и обновлять отображаемую цену на основании индекса порчи.

2. Автомат по п. 1, в котором центральный контроллер выполнен с возможностью разрешать покупателю безвозмездно заменить до N утилизированных товаров в течение транзакции и классифицировать событие утилизации, превышающее N, как условие злоупотребления.

3. Автомат по п. 2, в котором в ответ на условие злоупотребления центральный контроллер выполнен с возможностью добавить через платёжный терминал к транзакции плату как минимум за один утилизированный товар.

4. Автомат по п. 1, в котором регистр массы утилизации увеличивается при помещении товара в контейнер для утилизации, при этом учётная масса нагрузки на бункер событием утилизации не уменьшается.

5. Автомат по п. 1, в котором модуль ИИ-ценообразования рассчитывает индекс порчи как отношение накопленной массы утилизированных товаров к начальной или текущей массе нагрузки на бункер.

6. Автомат по п. 1, в котором модуль ИИ-ценообразования выполнен с возможностью снижать отображаемую цену, когда индекс порчи превышает пороговое значение.

7. Автомат по п. 1, в котором накопительный бункер содержит коническое днище бункера, выполненное с возможностью гравитационно направлять россыпные скоропортящиеся товары к центральной зоне взвешивания.

8. Автомат по п. 7, в котором коническое днище бункера имеет угол примерно 45 градусов относительно горизонтали.

9. Автомат по п. 7, в котором коническое днище бункера имеет угол в диапазоне примерно от 35 до 60 градусов относительно горизонтали.

10. Автомат по п. 7, в котором модуль взвешивания бункера содержит единственный центральный тензодатчик, расположенный в центральной зоне взвешивания и/или под ней.

11. Автомат по п. 10, в котором коническое днище бункера и единственный центральный тензодатчик выполнены с возможностью уменьшать погрешность угловой нагрузки, погрешность нагрузки на боковые стенки или сложность калибровки по сравнению с платформой бункера с несколькими тензодатчиками.

12. Автомат по п. 1, в котором накопительный бункер содержит автоматическую систему выравнивания уровня товара, расположенную внутри накопительного бункера и выполненную с возможностью перераспределять товары внутри бункера.

13. Автомат по п. 12, в котором автоматическая система выравнивания уровня товара содержит по меньшей мере одно из следующего: моторизованная разглаживающая лопасть, вращающаяся гребёнка, агитатор, вибропривод, колеблющаяся пластина, воздушная импульсная форсунка, шнек, подвижная напольная панель, наклонный перегородочный щиток, гибкий смыватель, грабли для товара или сервоприводное лезвие выравнивания.

14. Автомат по п. 12, в котором центральный контроллер активирует автоматическую систему выравнивания уровня товара в ответ по меньшей мере на одно из следующего: нестабильность показаний тензодатчика, обнаружение нагромождения товара по изображению, мостообразование товара, смещение к боковой стенке, дисбаланс датчика уровня в бункере, блокировку потока или ошибку дозирования.

15. Автомат по п. 12, в котором центральный контроллер приостанавливает или фильтрует измерения тензодатчика во время работы автоматической системы выравнивания уровня товара и возобновляет взвешивание после истечения интервала стабилизации или при выполнении условия стабильности массы.

16. Автомат по п. 1, в котором контейнер для утилизации содержит по меньшей мере одно из следующего: моторизованная крышка, односторонний приёмный слот, клапан, индикатор состояния, камера, считыватель RFID или конструкция, препятствующая извлечению.

17. Автомат по п. 1, в котором дисплей выполнен с возможностью отображать текущую цену за единицу, массу утилизированных товаров по транзакции и статус транзакции, выбранный из группы: доступна замена, достигнут лимит или применена плата за злоупотребление.

18. Автомат по п. 1, дополнительно содержащий датчик изображения, выполненный с возможностью обнаруживать признаки порчи или распределение товара внутри накопительного бункера, при этом модуль ИИ-ценообразования дополнительно использует данные изображения для корректировки цены или формирования уведомления оператору.

19. Способ эксплуатации автомата с накопительным (развесным) хранением, включающий: инициирование транзакции с покупателем; сброс счётчика утилизаций; предоставление покупателю возможности осмотреть товар из накопительного бункера; измерение тензодатчиком утилизации массы товара, помещённого в контейнер для утилизации; инкрементирование счётчика утилизаций; определение того, превышает ли счётчик утилизаций пороговое значение N; увеличение регистра массы утилизации без уменьшения учётной массы нагрузки на бункер; расчёт индекса порчи по регистру массы утилизации и массе нагрузки на бункер; и обновление отображаемой цены на основании индекса порчи.

20. Способ по п. 19, дополнительно включающий направление россыпных товаров в накопительном бункере к единственному центральному тензодатчику с помощью конического днища бункера с углом примерно 45 градусов относительно горизонтали и перераспределение россыпных товаров с помощью автоматической системы выравнивания уровня товара, расположенной внутри накопительного бункера.
