Claims1. An autonomous retail system comprising: (a) at least one secure enclosure defining a storage volume and having (i) a user access barrier movable between a locked state and an unlocked state and (ii) a service door enabling rear loading; (b) a locking mechanism coupled to the user access barrier; (c) a modular merchandising assembly within the storage volume comprising: (i) a chassis, (ii) one or more removable merchandising modules each defining a product presentation region and configured to be mounted to the chassis at any of a plurality of vertical positions, and (iii) a position‑adjustable interface that provides at least one of electrical power or data connectivity between the chassis and a merchandising module while permitting repositioning of the merchandising module between the plurality of vertical positions without disconnection; (d) an active motorized leveling system comprising motorized leveling feet having electric actuators, and an inclinometer coupled to the chassis; (e) a sensor suite comprising: (i) internal cameras disposed within the storage volume and configured for continuous visual tracking of user hand movement and item interaction, and (ii) an external user‑identification imaging sensor disposed on an exterior portion of the enclosure and oriented to capture user‑identifying imagery; (f) a selectable physical detection layer configured for at least two zone types including (A) a high‑value zone comprising at least one load cell and RFID sensing and (B) a standard zone comprising an optical beam sensor and a mechanical anti‑reverse inhibitor; (g) a shelf‑edge information system comprising an electronic display configured to present real‑time pricing and batch metadata for items in a product presentation region; (h) a user interface comprising a display and an input device, the user interface configured to present transaction terms and to receive an affirmative consent input; and (i) a controller coupled to the locking mechanism, the active motorized leveling system, the sensor suite, the selectable physical detection layer, the shelf‑edge information system, and the user interface, the controller being programmed to: (1) receive inclinometer data and automatically drive the electric actuators to level a cabinet frame when a detected tilt exceeds a threshold and inhibit transaction initiation when tilt remains above the threshold; (2) establish a user session using at least one of (A) a token decoded from an optical code presented by a mobile application or (B) biometric data captured using the external user‑identification imaging sensor; (3) reserve funds for the user session and, prior to unlocking the user access barrier, present transaction terms including at least a no‑returns policy and require receipt of the affirmative consent input; (4) unlock the user access barrier to permit manual retrieval of at least one item from the modular merchandising assembly; (5) detect item interaction and validate item removal by fusing outputs of the internal cameras with outputs of the selectable physical detection layer selected for a shelf zone; (6) maintain a virtual basket for the user session; and (7) route settlement proceeds for items in the virtual basket to one or more merchant accounts based on shelf‑specific sensor identifiers.2.
