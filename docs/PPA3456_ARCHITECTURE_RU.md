## Описание связей

| Блок | Назначение | Связи (стрелки) |
|------|------------|-----------------|
| **105 Биокамера** | Проверка возраста до доступа к age-gated товарам | → Контроллер 400 |
| **110 Дисплей** | Условия, цены, цифровой «сомелье», согласие | ↔ Контроллер 400 |
| **400 Контроллер** | Центр: слияние датчиков, цены, доступ, offline | ↔ Все модули и датчики |
| **Шина питания** | Питание и данные сменным модулям без перепайки | ↔ Модули A–G |
| **Зона перекрытия** | Камера + RFID + вес — подтверждение снятия | → Контроллер |
| **Модули A–G** | Разные типы товаров, ручное изъятие | → События снятия |
| **Умное стекло** | Непрозрачный → осмотр → доступ (алкоголь) | ← Контроллер |
| **Станция индукции** | Маркировка до загрузки (FIFO сзади) | → База контроллера |

**Ядро:** QR-токен + согласие + раздельные платежи + мультиаренда + master–slave + offline

## Описание связей

| Блок | Назначение | Связи (стрелки) |
|------|------------|-----------------|
| **QR / токен** | Сессия из KYC-приложения | → Сканер → Контроллер |
| **Модуль транзакций** | Pre-auth, согласие, корзина, split, offline | ↔ UI, замок, платёж |
| **UI согласия** | «Немедленное списание», «без возврата» — до unlock | → Запись согласия |
| **Интерфейс положения** | Шина питания/данных при смене высоты полки | ↔ Модули |
| **Внутренние датчики** | Fusion: RFID + вес + камера внутри объёма | → События снятия |
| **Master–slave** | Одна сессия, virtual basket на кластер | Master ↔ Slaves |
| **Multi-tenant** | Полки арендованы поставщикам | → Split по merchant ID |
| **Upstream manifest** | Товар помечен на складе поставщика | Сервер → Контроллер |

# PPA №5 — Ревизия: выравнивание, визуальный слой, ESL/FIFO

**Ядро:** моторизованное выравнивание + Visual Tracking Layer + ESL с очередью FIFO + облачная биометрия

## Блок-схема архитектуры

```
                    ┌─────────────────────────────────────────────────────────┐
                    │ 601 ИНКЛИНОМЕТР (датчик наклона)                          │
                    └───────────────────────────┬─────────────────────────────┘
                                                │ угол наклона
                                                ▼

                    │           КОНТРОЛЛЕР ШКАФА                                 │

                    │  │ Если наклон > 0,5° → моторизованные опоры →         │  │
                    │  │ ЗАПРЕТ транзакции до выравнивания                   │  │
                    │  └─────────────────────────────────────────────────────┘  │

                 │ · тензодатчик       │         │ · прерыватель луча  │
                 │ · RFID              │         │ · анти-возвратный   │

                                 │ СЛИЯНИЕ VTL +       │
                                 │ физический слой     │
                                 └──────────┬──────────┘
                                            │
              ┌─────────────────────────────┼─────────────────────────────┐
              ▼                             ▼                             ▼

     │ на краю полки   │         │ → сессия        │         │ по sensor ID    │
     │ FIFO очередь:   │         │                 │         │ полки           │
     │ цена + срок     │         └────────┬────────┘         └─────────────────┘
     │ след. товара    │                  │
     └─────────────────┘                  ▼

                                 │ Облачное        │

     │ Smart bin       │         │ Gravity tray    │
     │ (молоко в       │         │ + temp sensor   │
     │  пакетах)       │         │ блокировка      │
     └─────────────────┘         │ при перегреве   │
                                 └─────────────────┘

     Штраф: несанкц. возврат без VTL → кратность × max SKU
```

## Описание связей

| Блок | Назначение | Связи (стрелки) |
|------|------------|-----------------|
| **601 Инклинометр** | Измеряет наклон корпуса | → Контроллер → 602 опоры |
| **602 Опоры** | Авто-выравнивание до горизонта | ← Контроллер |
| **VTL (камеры)** | Непрерывное отслеживание рук и товаров | → Слияние с физ. слоем |
| **Зона высокой ценности** | Тензо + RFID для дорогих товаров | → Fusion |
| **Стандартная зона** | Луч + храповик без тензо (дешевле) | → Fusion |
| **603 ESL/LCD** | Цена и срок **следующего** в FIFO-очереди | ← Контроллер при снятии |
| **Облачная биометрия** | Регистрация после 1-й QR-сессии; роуминг | ↔ Контроллер всех шкафов |
| **Split по sensor ID** | Автоматический маршрут платежа по полке | ← Событие снятия |

# PPA №6 — Адаптивная архитектура, нагрев, ИИ-цены

**Ядро:** dual-zone climate + индукция + предоплата до нагрева + fluid station + floating bin + AI pricing

## Блок-схема архитектуры

```
                    ┌─────────────────────────────────────────────────────────┐
                    │  MASTER блок (опционально)                               │
                    │  Платёж · ИИ · оркестрация сессии · fiscal logic        │
                    └───────────────────────────┬─────────────────────────────┘
                                                │
                                                ▼
                    ┌───────────────────────────────────────────────────────────┐
                    │           КОНТРОЛЛЕР ШКАФА (standalone или slave)          │
                    │  ┌──────────────┐ ┌──────────────┐ ┌──────────────────┐  │
                    │  │ Авто-        │ │ Очередь      │ │ Модуль           │  │
                    │  │ выравнивание │ │ нагрева      │ │ ценообразования  │  │
                    │  │ inclinometer │ │ multi-order  │ │ ИИ bidirectional │  │
                    │  └──────────────┘ └──────────────┘ └──────────────────┘  │
                    └───────┬───────────────────────────────┬───────────────────┘
                            │                               │
         ┌──────────────────┴──────────────────┐            │
         ▼                                     ▼            ▼
┌─────────────────────────────┐    ┌─────────────────────────────┐

│ · профилированный канал     │    │ · индукционные катушки      │
│ · гравитационные полки      │    │ · LCD «ГОТОВО»             │
│ · плавающий smart bin       │    │ · Digital Passport (t°,     │
│ · RFID / LCD полки          │    │   профиль нагрева)          │
│                             │    │ · impedance auth упаковки   │
│ ─── тепловая шторка ───     │    │ · таймер выдачи · штраф     │
└──────────────┬──────────────┘    │   200% при abandonment      │
               │                   └──────────────┬──────────────┘
               │                                  │
               └──────────────────┬───────────────┘
                                  ▼
                    ┌─────────────────────────────────────────┐
                    │ 703 ГИБРИДНАЯ ЖИДКОСТНАЯ СТАНЦИЯ         │
                    │ · кипяток / пар · блокировка по SKU     │
                    │ · сухая добавка + заливка               │
                    └────────────────────┬────────────────────┘
                                         │
              ┌──────────────────────────┼──────────────────────────┐
              ▼                          ▼                          ▼
     ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
     │ 704 Диспенсер   │       │ 705 Желоб       │       │ QR / биометрия  │
     │ приборов        │       │ отходов         │       │ + карта слотов  │
     │ ложка·мешалка   │       │ просрочка ·     │       │ на мониторе     │
     │ по SKU          │       │ abandonment     │       │                 │
     └─────────────────┘       └─────────────────┘       └─────────────────┘

              ┌─────────────────────────────────────────────────┐
              │ ОБЛАКО                                            │
              │ · телеметрия парка · удалённые цены               │
              │ · условное бронирование (n>1 → walk-in priority)  │
              └─────────────────────────────────────────────────┘
              ▲
              │ мобильные приложения: поставщик + покупатель
```

## Описание связей

| Блок | Назначение | Связи (стрелки) |
|------|------------|-----------------|
| **Master** | Общий платёж и ИИ для кластера slave-шкафов | ↔ Контроллер шкафа |
| **701 Холодильник** | Хранение + каналы выдачи + floating bin | → События снятия / нагрева |
| **702 Нагрев** | Индукция по Digital Passport; pre-pay **до** нагрева | ← Оплата → Нагрев → Таймер |
| **Тепловая шторка** | Изоляция холодной и горячей зон | Между 701 и 702 |
| **703 Fluid station** | Разведение сухих добавок; interlock по SKU | ← Позиция товара подтверждена |
| **704 Приборы** | Выдача ложки/мешалки по типу блюда | ← SKU снятого товара |
| **705 Отходы** | Просрочка, невостребованный нагрев | ← Abandonment logic |
| **ИИ-цены** | Decay + surge + цены конкурентов; блокировка RFID | → LCD полки |
| **Облако** | Бронирование только при запасе >1 | ↔ Mobile app |
